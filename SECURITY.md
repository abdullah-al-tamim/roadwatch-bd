# Security and privacy

Do not use this development preview as a source of reliable driving directions. Community reports may be inaccurate, incomplete or outdated.

Location access is requested only through the location button. Coordinates are used on the device; travel history is not uploaded. A report's selected map coordinates and description are public while current. Authentication identity is not included in public incident reads. Email is handled by Supabase Authentication. Drafts remain in local browser storage.

Never identify individual officers, publish patrol movements, faces, number plates or personal information. Follow lawful traffic instructions. Interact only when safely stopped.

Automatic database deletion is disabled at the owner's request. Account deletion and moderation/appeals workflows must be completed before public beta. Until then, do not invite public contributions.

Report vulnerabilities privately through the repository owner's GitHub contact rather than posting credentials or location data in a public issue. Never commit .env.local, service-role keys, SMTP secrets or OAuth client secrets.
